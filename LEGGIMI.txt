CNC Factory — file da mettere sul server
========================================

In questo zip ci sono:
  index.html
  cnc.html              (la stessa pagina, con un altro nome)
  vendor/three.min.js   (motore 3D)
  vendor/peerjs.min.js  (gioco online con i colleghi)
  photos/               (volti, pavimento, pareti, tessuto, capelli, poster)

Carica TUTTI questi file sul server, nella stessa cartella.
Poi apri index.html oppure cnc.html dal browser, tramite il sito
(non con doppio clic dal disco).

Esempio:
  https://tuodominio.it/index.html
  https://tuodominio.it/cnc/index.html

Per il gioco online serve un sito in https (come GitHub Pages).
